# Source audit

Status: working audit structure. No source has been audited, downloaded, or approved for integration in Task 001.

The handoff names Mondo, HPO, and Open Targets as candidates, alongside unspecified gene/protein, biological-process, drug, and possible literature resources. These names record prior consideration only. Their current authority, location, releases, access conditions, licences, and coverage are NOT YET VERIFIED here.

## Per-source record

Use the following fields for each candidate once source investigation begins. An empty audit is not evidence of availability or suitability.

| Field | Evidence to record |
| --- | --- |
| Source | Exact resource name and role: ontology, assertions, identifiers, or literature. |
| Authority | Responsible organization and evidence for authorship/maintenance. |
| Official location | Verified authoritative URL. |
| Version/release | Exact inspected release and how it is identified. |
| Retrieval date | Actual access/acquisition date, distinguishing page review from data retrieval. |
| Licence | Verified terms and supporting location for the relevant artifact. |
| Access method | Supported acquisition mechanism, restrictions, and reproducibility implications. |
| Identifier system | Namespaces, identifier behavior, and deprecation/version handling. |
| Relevant entities | Entities needed by candidate questions, supported by inspected source material. |
| Relevant relationships | Source relationship meanings, direction, qualifiers, and intended use. |
| Provenance semantics | Assertion origin, evidence attribution, release attribution, and derivation information available. |
| Limitations | Coverage, missingness, conflicts, biases, and access limitations actually identified. |
| Overlap | Shared entities/assertions and dependence on other candidate sources. |
| Expected question coverage | Links to candidate question needs; distinguish expected from demonstrated coverage. |
| Redistribution constraints | Terms affecting raw data, transformed artifacts, and public releases. |
| Reason for inclusion | Requirement the source would satisfy and alternatives considered. |
| Verification status | NOT YET VERIFIED, partially checked with explicit gaps, or checked with evidence; selection approval recorded separately. |

## Selection gate

Assess whether the source provides the needed relationships with usable evidence and reproducible access. Do not infer mappings from similar names or interpret every association as a causal or therapeutic relationship. Source inclusion, external ontology selection, and mapping strategy require owner approval. Dataset acquisition is a later authorized operation; this document does not authorize downloads.
